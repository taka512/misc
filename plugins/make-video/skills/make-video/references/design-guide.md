# 説明画面のデザイン基準

ユーザーからデザイン指定がないときの既定値。見た目をそろえるための基準であり、本文のレイアウトを縛るものではない。

## キャンバスと領域

横長フルHD（1920×1080, 16:9）を基準とする。

| 領域 | 位置（目安） | 用途 |
|---|---|---|
| ヘッダー | x=76, y=40〜92 | 左上のシリーズ名・補助テキストと区切り線 |
| 説明領域 | x=76〜1220, y=120〜850 | 見出し・要点・図解 |
| 素材領域 | 右側 x=1296〜1920 | 縦長の操作画面（枠内に縦横比を保って配置） |
| 進捗バー | x=76〜1200, y=868 | 章の進行。章数で等分し、到達済みをアクセント色に |
| 字幕帯 | y=930〜1080 | 暗い帯の上に白文字、下中央、最大2行 |

- 横長の PC 画面を使う場合は右側の素材領域を使わず、画面の表示幅を優先して説明領域を縮める。
- 縦長の画面を横長の枠に押し込む、またはその逆はしない。

## 配色（既定）

| 名前 | 色 | 用途 |
|---|---|---|
| background | `#F5F7FA` | 背景 |
| panel | `#E6ECF5` | 右側の素材領域の下地 |
| frame | `#C3CEDD` | 画面枠 |
| ink | `#1B2A3A` | 本文 |
| muted | `#5B6B7F` | 補足 |
| accent | `#2F6FDE` | 強調・進捗バー（到達済み） |
| line | `#D8E0EA` | 区切り線・進捗バー（未到達） |
| subtitle_band | `#111315` | 字幕帯 |
| title_bg | `#1F4FA8` | 冒頭タイトルの背景 |

素材の色味と合わない場合は、アクセント色だけ素材に合わせて変えてよい。

## 文字

- 日本語フォントは実行環境で利用可能なものを確認して選ぶ（例: macOS は Hiragino Sans、Linux は Noto Sans CJK JP）。
- 目安サイズ: 見出し 56〜64px、本文 32〜36px、補足 24px、字幕 43px。
- 見出し・手順・補足の強弱を全編で統一する。文字が増えたら、はみ出さないよう文の区切りや配置を調整する。

## 冒頭タイトル

- `title_bg` の単色背景に、白文字のタイトルを中央配置し、下に小さく補足（シリーズ名など）を置く。
- 本文用のヘッダー・進捗バー・字幕帯は載せない。
- 使うかどうか、表示時間は合意した場面構成に従う。

## テンプレート画像の生成

`scripts/setup_env.sh` で用意した仮想環境の Python（以下 `$VENV/bin/python`）と `scripts/make_template.py` で既定の背景・共通部品を生成できる。設定を変えたい場合は `--config` に JSON を渡す（キーはスクリプト冒頭の `DEFAULT` を参照）。

```bash
# 作業ディレクトリに出力（スキル内には出力しない）
"$VENV/bin/python" scripts/make_template.py --out work/template

# 章ごとの共通部品（進捗バー）を生成
"$VENV/bin/python" scripts/make_template.py --out work/template \
  --chapters 概要 準備 操作 まとめ --current 2
```

出力:

- `background.png`: 背景と字幕帯
- `portrait-layout.png`: 背景 + 縦長画面用の枠
- `components-chN.png`: 透過のヘッダーと進捗バー（章 N 用）
- `title.png`: 冒頭タイトル（`--title` / `--title-sub` で文字を指定）

背景を最背面に置き、共通部品・説明文・画面素材・字幕を別レイヤーとして重ねる。
